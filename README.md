## Selected Work

### 🧭 [PickStay](https://github.com/yiyuanlee/PickStay) · [Live Demo](https://pickstay.vercel.app)

A full-stack neighborhood recommender that matches travelers with places to stay based on seven weighted preferences.

- Built an explainable recommendation engine for **57 neighborhoods across 8 cities**, with radar-chart comparisons and shareable preference links
- Engineered authentication and persistent user data with **Supabase PostgreSQL + RLS**, plus server-side map enrichment with Redis caching, rate limiting, fallback data, and automated tests

**Stack:** Next.js 16 · React 19 · TypeScript · Supabase · Upstash Redis · Vitest · Playwright · Vercel

### 📈 [AlphaFlow](https://github.com/yiyuanlee/AlphaFlow)

A modular Python research and trading system for Interactive Brokers.

- Shared strategy and indicator modules across backtesting, walk-forward validation, and trading adapters to keep research and execution logic aligned
- Added configuration-driven workflows, risk controls, and pytest indicator-parity checks for reproducible experiments

**Stack:** Python · Backtrader · pytest · IBKR API · Yahoo Finance

### ⚽ [26 World Cup Predictor](https://github.com/yiyuanlee/26worldcup_predictor)

A football match prediction service that combines historical performance data with live market odds.

- Engineers prediction inputs from head-to-head records, recent form, home/away performance, rankings, and implied probabilities
- Exposes FastAPI endpoints for competitions, teams, data synchronization, and predictions, with a browser-based interface

**Stack:** Python · FastAPI · football-data.org · The Odds API
